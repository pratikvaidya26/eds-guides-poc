Installing or upgrading InfoScale InfoScale by using the installer as a sudo user

Starting with InfoScale 8.0.2, you can install or upgrade InfoScale running on Red Hat, SLES, and Oracle Linux using a sudo user. Run ./installer -sudouser <username of the sudo user>.
