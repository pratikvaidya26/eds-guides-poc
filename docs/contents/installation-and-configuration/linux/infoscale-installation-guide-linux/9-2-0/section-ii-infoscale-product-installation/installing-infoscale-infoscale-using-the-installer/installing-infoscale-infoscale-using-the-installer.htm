Installing InfoScale InfoScale using the installer

The product installer is the recommended method to license and install InfoScale InfoScale.
To install InfoScale:
  1. Load and mount the software disc. If you downloaded the software, navigate to the top level of the download directory and skip the next step.
  2. Move to the top-level directory on the disc.
    \# cd /mnt/cdrom
  3. From this directory, type the following command to start the installation on the local system.
    \# ./installer
  4. Press I to install and pressEnter.
  5. The list of available products is displayed. Select the product that you want to install on your system.
    1)  Veritas Foundation

    2)  Veritas Availability

    3)  Veritas InfoScale Storage

    4)  Veritas InfoScale Enterprise

    b)  Back to previous menu

    Select a product to install: [1-4,b,q]









  6. You are prompted to configure the product. For example, if you had specified 4 in the earlier step, the following message is displayed:
    Would you like to configure InfoScale Enterprise after installation?

    [y,n,q]

    If you enter y, the installer configures the product after installation. If you enter**n** , the installer quits after the installation is complete.
  7. At the prompt, specify whether you accept the terms of the End User License Agreement (EULA). Enter y.
    Do you agree with the terms of the End User License Agreement as

    specified in the EULA/en/EULA.pdf file

    present on media? [y,n,q,?] y



  8. If you did not specify the systems where you want to install the product when you ran the installer, you are prompted to specify the system names. You can specify the host names or IP addresses. The installer performs the pre-checks.
  9. Specify whether you want to provide the license key.
    Would you like to license the systems? [y,n,q] (y)
    Entering y prompts you to provide the path to the license key file located on the node running the installer. The installer then registers the license key and displays the following confirmation message:
    Successfully registered user-defined key <path to the license key>
    If you specify n, InfoScale services will not start post-installation. To decline running without a license and return to the licensing setup, enter n again and specify the path to the license key file.
    Would you like to license the systems? [y,n,q] (y) n 

    Services will not start post installation, Do you want to continue without license? [y,n,q] (n) n

    Enter a valid license key file path on the node where installer is running: [b]



    If you choose to proceed with the installation without a license, the installation process continues. However InfoScale services will not start and you will be unable to configure the product. InfoScale services will remain offline until you apply a valid license using either ./installer -license or vxlicinstupgrade -k lic_key command.
  10. Specify whether you want to configure the REST server.
    The install program needs to make the following configuration

    changes to enable REST server support:

    Configure the clusters in Secure mode.



    Do you want to configure REST API Server? [y,n,q,?] (n)







    If you enter y , the cluster is automatically configured in the secure mode. At a later point, the installer prompts you to provide further input that is required for the REST server configurations. For details, refer to the InfoScale Solutions Guide.
  11. Check the log file to confirm the installation. The log files, summary file, and response file are saved at: /opt/VRTS/install/logs directory.
