Installing InfoScale using Kickstart

You can install InfoScale using Kickstart. Kickstart is supported for Red Hat Enterprise Linux operating system.
To install InfoScale using Kickstart
  1. Create a directory for the Kickstart configuration files.
    \# mkdir /kickstart_files/
    1. Generate the Kickstart configuration files. The configuration files have the extension .ks. :
    Enter the following command:
    \# ./installer -kickstart /kickstart_files/
The system lists the files.
The output includes the following:
The kickstart script for ENTERPRISE is generated at

/kickstart_files/kickstart_enterprise.ks

  1. Set up an NFS exported location which the Kickstart client can access. For example, if /nfs_mount_kickstart is the directory which has been NFS exported, the NFS exported location may look similar to the following:
    \# cat /etc/exports

    /nfs_mount_kickstart  * (rw,sync,no_root_squash)

    1. Copy the rpms directory from the installation media to the NFS location.
    2. Verify the contents of the directory.
    \# ls /nfs_mount_kickstart/
  2. In the InfoScale Kickstart configuration file, modify the BUILDSRC variable to point to the actual NFS location. The variable has the following format:
    BUILDSRC="hostname_or_ip:/nfs_mount_kickstart"
    1. Append the entire modified contents of the Kickstart configuration file to the operating system ks.cfg file.
    2. Launch the Kickstart installation for the operating system.
    3. After the operating system installation is complete, check the file /opt/VRTStmp/kickstart.log for any errors that are related to the installation of RPMs and product installer scripts.
    4. Verify that all the product RPMs have been installed. Enter the following command:
    \# rpm -qa | grep -i vrts
  3. If you do not find any installation issues or errors, configure the product stack. Enter the following command:
\# /opt/VRTS/install/installer -configure sys1 sys2
