Kickstart is supported for Red Hat Enterprise Linux operating system.</p><p class="- topic/p ">To install InfoScale using Kickstart</p><ol class="- topic/ol "><li class="- topic/li "><p class="- topic/p ">Create a directory for the Kickstart configuration files.</p><codeblock class="+ topic/pre pr-d/codeblock " xml:space="preserve" outputclass="bash">\# mkdir /kickstart_files/</codeblock><ol class="- topic/ol "><li class="- topic/li "><p class="- topic/p ">Generate the Kickstart configuration files. The configuration files have the extension <codeph class="+ topic/ph pr-d/codeph ">.ks</codeph>. :</p></li></ol><p class="- topic/p ">Enter the following command:</p><codeblock class="+ topic/pre pr-d/codeblock " xml:space="preserve" outputclass="bash">\# ./installer -kickstart /kickstart_files/</codeblock></li></ol><p class="- topic/p ">The system lists the files.</p><p class="- topic/p ">The output includes the following:</p><codeblock class="+ topic/pre pr-d/codeblock " xml:space="preserve" outputclass="txt">The kickstart script for ENTERPRISE is generated at
/kickstart_files/kickstart_enterprise.ks</codeblock><ol class="- topic/ol "><li class="- topic/li "><p class="- topic/p ">Set up an NFS exported location which the Kickstart client can access. For example, if <codeph class="+ topic/ph pr-d/codeph ">/nfs_mount_kickstart</codeph> is the directory which has been NFS exported, the NFS exported location may look similar to the following:</p><codeblock class="+ topic/pre pr-d/codeblock " xml:space="preserve" outputclass="bash">\# cat /etc/exports
/nfs_mount_kickstart  * (rw,sync,no_root_squash)</codeblock><ol class="- topic/ol "><li class="- topic/li "><p class="- topic/p ">Copy the <codeph class="+ topic/ph pr-d/codeph ">rpms</codeph> directory from the installation media to the NFS location.</p></li><li class="- topic/li "><p class="- topic/p ">Verify the contents of the directory.</p></li></ol><codeblock class="+ topic/pre pr-d/codeblock " xml:space="preserve" outputclass="bash">\# ls /nfs_mount_kickstart/</codeblock></li><li class="- topic/li "><p class="- topic/p ">In the InfoScale Kickstart configuration file, modify the <codeph class="+ topic/ph pr-d/codeph ">BUILDSRC</codeph> variable to point to the actual NFS location. The variable has the following format:</p><codeblock class="+ topic/pre pr-d/codeblock " xml:space="preserve" outputclass="txt">BUILDSRC="hostname_or_ip:/nfs_mount_kickstart"</codeblock><ol class="- topic/ol "><li class="- topic/li "><p class="- topic/p ">Append the entire modified contents of the Kickstart configuration file to the operating system <codeph class="+ topic/ph pr-d/codeph ">ks.cfg</codeph> file.</p></li><li class="- topic/li "><p class="- topic/p ">Launch the Kickstart installation for the operating system.</p></li><li class="- topic/li "><p class="- topic/p ">After the operating system installation is complete, check the file <codeph class="+ topic/ph pr-d/codeph ">/opt/VRTStmp/kickstart.log</codeph> for any errors that are related to the installation of RPMs and product installer scripts.</p></li><li class="- topic/li "><p class="- topic/p ">Verify that all the product RPMs have been installed. Enter the following command:</p></li></ol><codeblock class="+ topic/pre pr-d/codeblock " xml:space="preserve" outputclass="bash">\# rpm -qa | grep -i vrts</codeblock></li><li class="- topic/li "><p class="- topic/p ">If you do not find any installation issues or errors, configure the product stack. Enter the following command:</p></li></ol><codeblock class="+ topic/pre pr-d/codeblock " xml:space="preserve" outputclass="bash">\# /opt/VRTS/install/installer -configure sys1 sys2</codeblock></body></topic>
