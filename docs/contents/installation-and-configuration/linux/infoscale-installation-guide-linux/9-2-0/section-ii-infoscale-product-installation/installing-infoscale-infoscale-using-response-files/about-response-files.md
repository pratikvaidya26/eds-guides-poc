The response file contains the configuration information that you entered during the procedure. When the procedure completes, the installation script displays the location of the response files.</p><p class="- topic/p ">You can use the response file for future installation procedures by invoking an installation script with the <codeph class="+ topic/ph pr-d/codeph ">-responsefile</codeph> option. You can edit the file to automate installation and configuration of additional systems.</p><p class="- topic/p ">You can also use <codeph class="+ topic/ph pr-d/codeph ">-makeresponsefile</codeph> option to generate a <codeph class="+ topic/ph pr-d/codeph ">responsefile</codeph>. This response file is used for unattended installations in the future. Run <codeph class="+ topic/ph pr-d/codeph ">./installer -makeresponsefile</codeph> with the option you want.</p><lq class="- topic/lq "><p class="- topic/p "><b class="+ topic/ph hi-d/b ">Note:</b> InfoScale recommends that you use the response file created by the installer and then edit it as per your requirement.</p></lq></body></topic>
