Removing the InfoScale public key

Removing the InfoScale public key

The process for deleting the InfoScale public key from the system is similar to the steps for adding the key. If the Secure Boot feature is enabled and you delete the InfoScale public key from a system, you cannot load any signed kernel modules from the InfoScale packages on that system.
Verify the following before you proceed:
  • Ensure that you have administrative privileges on the system.
  • Ensure that you have console access to the systems (Web Console access in case of VMware virtual machines). Console access is required to access the UEFI Setup Screen during system startup.
To remove the InfoScale public key
  1. Connect to an InfoScale system using ssh and then navigate to the location that contains the InfoScale public key.
  2. To delete the key, run the following command from the directory that contains the key:
# mokutil --delete pubkey.der
  1. On the password prompt, enter the password that is associated with that key.
Then type the same password again to confirm.
  1. To remove the imported public key from the Machine Owner Key (MOK) database on the system, switch to the console view of the system and then restart the system.
  2. At system boot, the UEFI key management screen appears for a few seconds. Quickly press any key to enter the MOK management interface.
    Note: If you miss the UEFI key management screen at startup, restart the system and try again.
  3. On the Perform MOK management screen, select Delete MOK and pressEnter.
  4. On the Delete MOK screen, select Continue and pressEnter.
  5. On the Delete the keys(s)? screen, select Yes and pressEnter.
  6. On the password prompt, type the password that you assigned to the public key and then press Enter.
  7. On the Perform MOK management screen, select Reboot and pressEnter to restart the system.
  8. To verify that the public key is successfully removed, connect to the system again using ssh and type the following command at the terminal:
# mokutil --list-enrolled
The InfoScale public key no longer appears in the list of enrolled keys on the system.
The process of removing the InfoScale public key from the system is now complete. Repeat these steps on each system from where you intend to delete the InfoScale public key.
