If the Secure Boot feature is enabled and you delete the InfoScale public key from a system, you cannot load any signed kernel modules from the InfoScale packages on that system.</p><p class="- topic/p ">Verify the following before you proceed:</p><ul class="- topic/ul "><li class="- topic/li "><p class="- topic/p ">Ensure that you have administrative privileges on the system.</p></li><li class="- topic/li "><p class="- topic/p ">Ensure that you have console access to the systems (Web Console access in case of VMware virtual machines). Console access is required to access the UEFI Setup Screen during system startup.</p></li></ul><p class="- topic/p ">To remove the InfoScale public key</p><ol class="- topic/ol "><li class="- topic/li "><p class="- topic/p ">Connect to an InfoScale system using ssh and then navigate to the location that contains the InfoScale public key.</p></li><li class="- topic/li "><p class="- topic/p ">To delete the key, run the following command from the directory that contains the key:</p></li></ol><p class="- topic/p "><codeph class="+ topic/ph pr-d/codeph "># mokutil --delete pubkey.der</codeph></p><ol class="- topic/ol "><li class="- topic/li "><p class="- topic/p ">On the password prompt, enter the password that is associated with that key.</p></li></ol><p class="- topic/p ">Then type the same password again to confirm.</p><ol class="- topic/ol "><li class="- topic/li "><p class="- topic/p ">To remove the imported public key from the Machine Owner Key (MOK) database on the system, switch to the console view of the system and then restart the system.</p></li><li class="- topic/li "><p class="- topic/p ">At system boot, the UEFI key management screen appears for a few seconds. Quickly press any key to enter the MOK management interface.</p><image class="- topic/image " href="../../../../../../media/img/image_ee02d50c6142.png" placement="break"><alt class="- topic/alt ">image</alt></image><lq class="- topic/lq "><p class="- topic/p "><b class="+ topic/ph hi-d/b ">Note:</b> If you miss the UEFI key management screen at startup, restart the system and try again.</p></lq></li><li class="- topic/li "><p class="- topic/p ">On the Perform MOK management screen, select <b class="+ topic/ph hi-d/b ">Delete MOK <b class="+ topic/ph hi-d/b ">and press</b><codeph class="+ topic/ph pr-d/codeph ">Enter</codeph></b>.</p><image class="- topic/image " href="../../../../../../media/img/image_f8efb1680342.png" placement="break"><alt class="- topic/alt ">image</alt></image></li><li class="- topic/li "><p class="- topic/p ">On the Delete MOK screen, select <b class="+ topic/ph hi-d/b ">Continue <b class="+ topic/ph hi-d/b ">and press</b><codeph class="+ topic/ph pr-d/codeph ">Enter</codeph></b>.</p></li><li class="- topic/li "><p class="- topic/p ">On the Delete the keys(s)? screen, select <b class="+ topic/ph hi-d/b ">Yes <b class="+ topic/ph hi-d/b ">and press</b><codeph class="+ topic/ph pr-d/codeph ">Enter</codeph></b>.</p></li><li class="- topic/li "><p class="- topic/p ">On the password prompt, type the password that you assigned to the public key and then press <b class="+ topic/ph hi-d/b "><codeph class="+ topic/ph pr-d/codeph ">Enter</codeph></b>.</p><image class="- topic/image " href="../../../../../../media/img/image_0f886f2a03e1.png" placement="break"><alt class="- topic/alt ">image</alt></image></li><li class="- topic/li "><p class="- topic/p ">On the Perform MOK management screen, select <b class="+ topic/ph hi-d/b ">Reboot <b class="+ topic/ph hi-d/b ">and press</b><codeph class="+ topic/ph pr-d/codeph ">Enter</codeph></b> to restart the system.</p><image class="- topic/image " href="../../../../../../media/img/image_fea44c02170c.png" placement="break"><alt class="- topic/alt ">image</alt></image></li><li class="- topic/li "><p class="- topic/p ">To verify that the public key is successfully removed, connect to the system again using ssh and type the following command at the terminal:</p></li></ol><p class="- topic/p "><codeph class="+ topic/ph pr-d/codeph "># mokutil --list-enrolled</codeph></p><p class="- topic/p ">The InfoScale public key no longer appears in the list of enrolled keys on the system.</p><p class="- topic/p ">The process of removing the InfoScale public key from the system is now complete. Repeat these steps on each system from where you intend to delete the InfoScale public key.</p></body></topic>
