Appendix D. Managing InfoScale digital signatures (Secure Boot environment)
Verify an InfoScale module signature key

Verify an InfoScale module signature key

The following InfoScale kernel modules are digitally signed:
- vxfs
- vxfen
- gms
- veki
- vcsmm
- odm
- llt
- amf
- vxvm
- gab
- glm
To verify if an InfoScale kernel module is digitally signed, connect to an InfoScale system using ssh and type the following command:
# modinfo infoscalemodulename | grep key
Here, *infoscalemodulename* is the name of the InfoScale kernel module.
For example, to view the signature key for vxfs, the command is as follows:
# modinfo vxfs | grep key
The following output confirms that the module is signed:
signer: Veritas Technologies LLC Kernel signing key

sig_key: 31:60:A1:4B:8D:3A:AF:9E:94:C4:A6:F8:56:08:CE:0C:84:BD:B8:75
