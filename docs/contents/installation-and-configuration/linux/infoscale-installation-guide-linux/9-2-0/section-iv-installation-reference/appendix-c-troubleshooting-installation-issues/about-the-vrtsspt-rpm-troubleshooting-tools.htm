About the VRTSspt RPM troubleshooting tools

The VRTSspt RPM provides a group of tools for troubleshooting a system and collecting information on its configuration. If you install and use the VRTSspt RPM, it will be easier for InfoScale Support to diagnose any issues you may have.
The tools can gather File System (VxFS) and Volume Manager (VxVM) metadata information and establish various benchmarks to measure file system and volume manager performance. Although the tools are not required for the operation of any InfoScale InfoScale product, InfoScale recommends installing them should a support case be needed to be opened with InfoScale Support. Use caution when you use the VRTSspt RPM, and always use it in concert with InfoScale Support.
