Then, import and enroll that key to the Machine Owner Key (MOK) database on each system.</p><p class="- topic/p ">Verify the following before you proceed:</p><ul class="- topic/ul "><li class="- topic/li "><p class="- topic/p ">Ensure that the Secure Boot feature is enabled on the system.</p></li><li class="- topic/li "><p class="- topic/p ">Ensure that you have administrative privileges on the system.</p></li><li class="- topic/li "><p class="- topic/p ">Ensure that you have console access to the systems (Web Console access in case of VMware virtual machines). Type the following command:</p></li></ol><p class="- topic/p "><codeph class="+ topic/ph pr-d/codeph "># ls</codeph></p><p class="- topic/p ">A key named <codeph class="+ topic/ph pr-d/codeph ">pubkey.der</codeph> appears in the list of local files and directories, as shown:</p><codeblock class="+ topic/pre pr-d/codeblock " xml:space="preserve" outputclass="txt">Boot    etc    lib64    mnt_12345    proc    run    src    usr afs    bin    home
media    sys    var    sbin    dev    lib mnt    opt    root    pubkey.der</codeblock><ol class="- topic/ol "><li class="- topic/li "><p class="- topic/p ">Import the downloaded public key on the system using the following command:</p></li></ol><p class="- topic/p "><codeph class="+ topic/ph pr-d/codeph "># mokutil --import pubkey.der</codeph></p><ol class="- topic/ol "><li class="- topic/li "><p class="- topic/p ">On the password prompt, assign a password for the public key.</p></li></ol><p class="- topic/p ">Then type the same password again to confirm the password.</p><lq class="- topic/lq "><p class="- topic/p "><b class="+ topic/ph hi-d/b ">Note:</b> Make a note of this password. The password is required in the subsequent step for enrolling the key in the system MOK. The same password is also required if you want to delete the key from the system.</p></lq><ol class="- topic/ol "><li class="- topic/li "><p class="- topic/p ">To add the imported public key to the Machine Owner Key (MOK) database on the system, switch to the console view of the system and then restart the system.</p></li><li class="- topic/li "><p class="- topic/p ">At system boot, the UEFI key management screen appears for a few seconds. topic/ph hi-d/b ">and press</b><codeph class="+ topic/ph pr-d/codeph ">Enter</codeph></b>.</p></li><li class="- topic/li "><p class="- topic/p ">On the Enroll the key(s) screen, select <b class="+ topic/ph hi-d/b ">Yes <b class="+ topic/ph hi-d/b ">and press</b><codeph class="+ topic/ph pr-d/codeph ">Enter</codeph></b>.</p></li><li class="- topic/li "><p class="- topic/p ">On the password
