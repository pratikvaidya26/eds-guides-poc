Verifying the systems before installation

Verify your systems before installation.
Run the installer with the "-precheck" option as follows:
Navigate to the directory that contains the installation program.
Run the installation program to start the pre-check process:
\# ./installer -precheck sys1 sys2
Here, sys1, sys2 are the names of the nodes in the cluster.
The program proceeds in a non-interactive mode, examining the systems for licenses, RPMs, disk space, and system-to-system communications. The program displays the results of the pre-check and saves them in a log file. The location of the log file is displayed at the end of the pre-check process.
