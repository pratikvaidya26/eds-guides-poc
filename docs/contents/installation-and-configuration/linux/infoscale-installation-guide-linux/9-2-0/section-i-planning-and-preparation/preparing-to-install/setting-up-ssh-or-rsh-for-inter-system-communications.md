During an installation, you choose the communication method that you want to use. Or, you can run the <codeph class="+ topic/ph pr-d/codeph ">installer -comsetup</codeph> command to set up ssh or rsh explicitly. When the installation process completes, the installer asks you if you want to remove the password-less connection.
