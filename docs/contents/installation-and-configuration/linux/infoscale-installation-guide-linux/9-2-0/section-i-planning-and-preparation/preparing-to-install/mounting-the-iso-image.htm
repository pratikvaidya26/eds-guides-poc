Mounting the ISO image

An ISO file is a disc image that must be mounted to a virtual drive for use. You must have superuser (root) privileges to mount the InfoScale InfoScale ISO image.
To mount the ISO image
  1. Log in as superuser on a system where you want to install InfoScale InfoScale.
  2. Mount the image:
\# mount -o loop <ISO_image_path> /mnt
