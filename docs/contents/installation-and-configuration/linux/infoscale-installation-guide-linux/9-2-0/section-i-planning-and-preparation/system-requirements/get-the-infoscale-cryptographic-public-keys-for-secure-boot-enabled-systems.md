<?xml version="1.0" encoding="utf-8"?><?workdir /opt/aem/launcher/profiles/ditamaps/ditamap8329419222281724652/PDFProject/contents/installation-and-configuration/linux/infoscale-installation-guide-linux/9-2-0/section-i-planning-and-preparation/system-requirements?><?workdir-uri file:/opt/aem/launcher/profiles/ditamaps/ditamap8329419222281724652/PDFProject/contents/installation-and-configuration/linux/infoscale-installation-guide-linux/9-2-0/section-i-planning-and-preparation/system-requirements/?><?path2project ../../?><?path2project-uri ../../?><?path2rootmap-uri ../../?><topic xmlns:ditaarch="http://dita.oasis-open.org/architecture/2005/" xmlns:dita-ot="http://dita-ot.sourceforge.net/ns/201007/dita-ot" class="- topic/topic " ditaarch:DITAArchVersion="1.2" domains="(topic hi-d) (topic ut-d) (topic indexing-d) (topic hazard-d) (topic abbrev-d) (topic pr-d) (topic sw-d) (topic ui-d)" id="get-the-infoscale-cryptographic-public-keys-for-secure-boot-enabled-systems"><title class="- topic/title ">Get the InfoScale cryptographic public keys (for Secure Boot-enabled systems)</title><body class="- topic/body "><p class="- topic/p ">This requirement is applicable only if you plan to deploy InfoScale on the systems where the Secure Boot feature is enabled.</p><p class="- topic/p ">InfoScale kernel modules are digitally signed using public-private key pairs. You must obtain the InfoScale cryptographic public keys and then enroll the keys on each system where you intend to install InfoScale. The operating system kernel validates the digital signatures and authenticates the integrity of the kernel modules. You must download and enroll the keys on each system before you install and configure InfoScale.</p><p class="- topic/p ">You can obtain the InfoScale public keys using any of the methods described here.</p><p class="- topic/p ">Download the public key from the InfoScale Download Center.</p><p class="- topic/p ">You can download the InfoScale public key directly from SORT.</p><p class="- topic/p ">To get the public key from SORT</p><ol class="- topic/ol "><li class="- topic/li "><p class="- topic/p ">Download the public key from the following URL:</p><p class="- topic/p "><xref class="- topic/xref " href="https://downloads.infoscale.com/tools/secure-boot-key" format="html" scope="external"><?ditaot usertext?>InfoScale Download Center</xref></p><p class="- topic/p ">You must sign in to download the infoscale-pubkey.der key.</p></li><li class="- topic/li "><p class="- topic/p ">Validate the integrity of the file using the SHA256sum algorithm method.</p><p class="- topic/p ">Run the following command:</p><p class="- topic/p "><codeph class="+ topic/ph pr-d/codeph "># sha256sum pubkey.der</codeph></p><p class="- topic/p ">The command displays an output in the following format:</p><codeblock class="+ topic/pre pr-d/codeblock " xml:space="preserve" outputclass="txt">hashvalue pubkey.der</codeblock><p class="- topic/p ">Here, <i class="+ topic/ph hi-d/i ">hashvalue</i> is an alpha numeric sequence that represents the SHA256 checksum and is unique to the public key file.</p><p class="- topic/p ">For example,</p><codeblock class="+ topic/pre pr-d/codeblock " xml:space="preserve" outputclass="txt">bd00eeb8b4c0e63f1062aa0d pubkey.der</codeblock><p class="- topic/p ">The hash value displayed here in the example is just for reference; the actual hash value for the file will vary.</p></li><li class="- topic/li "><p class="- topic/p ">Compare the hash value with the SHA256sum hash value displayed on the following URL:</p><p class="- topic/p "><xref class="- topic/xref " href="https://downloads.infoscale.com/tools/secure-boot-key" format="html" scope="external"><?ditaot usertext?>infoscale_key</xref></p><p class="- topic/p ">If the file hash values match, it confirms that the file is authentic and has not been tampered with.</p><p class="- topic/p ">You can now import the file on the InfoScale nodes.</p></li></ol><p class="- topic/p ">See <xref class="- topic/xref " href="../preparing-to-install/preparing-for-deployment-in-a-secure-boot-environment.md" dita-ot:orig-format="markdown" format="dita" type="topic"><?ditaot usertext?>Preparing for deployment in a Secure Boot environment</xref>.</p><p class="- topic/p ">Extract the public key from VRTSveki</p><p class="- topic/p ">You can retrieve the InfoScale public key from the <codeph class="+ topic/ph pr-d/codeph ">VRTSveki</codeph> rpm package that is included with the InfoScale software.</p><p class="- topic/p ">To extract the public key from VRTSveki</p><ol class="- topic/ol "><li class="- topic/li "><p class="- topic/p ">Download the InfoScale software image.</p></li><li class="- topic/li "><p class="- topic/p ">Locate and copy the <codeph class="+ topic/ph pr-d/codeph ">VRTSveki</codeph> rpm file to a temporary directory.</p></li></ol><p class="- topic/p ">The name of the <codeph class="+ topic/ph pr-d/codeph ">VRTSveki</codeph> rpm may vary depending on the InfoScale release version. For example, for version 8.0.2, the rpm file name is "<codeph class="+ topic/ph pr-d/codeph ">VRTSveki-8.0.2.0000-RHEL8.x86_64.rpm</codeph>".</p><ol class="- topic/ol "><li class="- topic/li "><p class="- topic/p ">Extract the public key from the rpm file.</p></li></ol><p class="- topic/p ">Run the following command from the location where you copied the rpm file:</p><p class="- topic/p "><codeph class="+ topic/ph pr-d/codeph "># rpm2cpio VRTSveki-8.0.2.0000-RHEL8.x86_64.rpm | cpio -dimv ./etc/vx/kernel/infoscale-pubkey.der</codeph></p><p class="- topic/p ">The output displays the following:</p><codeblock class="+ topic/pre pr-d/codeblock " xml:space="preserve" outputclass="txt">./etc/vx/kernel/infoscale-pubkey.der
12705 blocks</codeblock><p class="- topic/p ">Here, "<codeph class="+ topic/ph pr-d/codeph ">infoscale-pubkey.der</codeph>" is the InfoScale cryptographic public key and it is saved in the directory <codeph class="+ topic/ph pr-d/codeph ">/etc/vx/kernel</codeph>.</p><ol class="- topic/ol "><li class="- topic/li "><p class="- topic/p ">If required, copy the key to a different location and then rename the file as <codeph class="+ topic/ph pr-d/codeph ">pubkey.der</codeph>.</p></li></ol><p class="- topic/p ">Type the following command:</p><p class="- topic/p "><codeph class="+ topic/ph pr-d/codeph "># mv infoscale-pubkey.der pubkey.der</codeph></p><p class="- topic/p ">You can now import the file on the InfoScale nodes.</p><p class="- topic/p ">See <xref class="- topic/xref " href="../preparing-to-install/preparing-for-deployment-in-a-secure-boot-environment.md" dita-ot:orig-format="markdown" format="dita" type="topic"><?ditaot usertext?>Preparing for deployment in a Secure Boot environment</xref>.</p></body></topic>
