About the vxlicinstupgrade utility

The vxlicinstupgrade utility enables you to perform the following tasks:
  • Upgrade to a subscription-based InfoScale license
  • Manage co-existence of multiple licenses
This utility handles license addition and removal of licenses with built-in validation checks:
  • Rejects the older keyless and permanent licenses.
  • Version upgrade: When installing a higher-version license key over an older one (e.g., upgrading from 7.0 to 9.1), the vxlicinstupgrade utility installs the new license file at /etc/vx/licenses/lic and automatically deletes the older version.
  • Does not support pre-7.4 text-based license keys.
Note: When registering license key files manually during upgrade, you have to use the vxlicinstupgrade command. When registering keys using the installer script, the same procedures are performed automatically.
