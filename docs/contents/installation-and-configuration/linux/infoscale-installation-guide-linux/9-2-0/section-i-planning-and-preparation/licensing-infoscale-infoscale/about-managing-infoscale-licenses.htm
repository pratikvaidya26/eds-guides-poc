About managing InfoScale licenses

You can manage your licenses by using the vxlicinstupgrade utility, which is located in the product installation directory.
To add a subscription license, run the following commands: \# cd /opt/VRTS/bin\# ./vxlicinstupgrade -k <key-filepath> where, the <key-filepath> is the absolute path of the .lic license key file saved on the current node. Example: /downloads/InfoScale_keys/XYZ.lic
