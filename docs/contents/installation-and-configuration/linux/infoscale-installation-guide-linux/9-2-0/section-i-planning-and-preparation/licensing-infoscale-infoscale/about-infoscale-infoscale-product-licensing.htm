About InfoScale product licensing

InfoScale has transitioned to a new subscription-based licensing model that introduces active, controlled enforcement of product entitlements. Permanent and keyless licenses are replaced by a universal, subscription-based license that aligns directly with your subscription entitlement's end-date. While older InfoScale licensing models were non-enforcing and relied solely on notification messages, the new model actively tracks the license lifecycle. By eliminating multiple license types based on core counts and platform-specific entitlements, InfoScale has simplified license management with a single subscription-based license key for all the variants of the InfoScale product. This shift to a single subscription license key reduces administrative overhead, making installation, renewal, and tracking significantly simpler while giving customers a clear, controlled timeline to manage renewals before any functionality is impacted.

Understanding the license lifecycle

Previously, licenses were non-enforcing, only generating notification messages upon expiry while product functionality continued indefinitely. The new behavior actively enforces the license lifecycle, impacting functionality and transitioning the product through Warning, Grace, and Enforced states. A controlled enforcement of licenses ensures customers have sufficient time to renew licenses without service disruption. When an active subscription begins nearing its end, the product transitions through three distinct lifecycle states designed to communicate urgency while preventing immediate operational failure:

License logging service

The infoscaleLicense service monitors license compliance across cluster nodes. This service automatically starts following the installation or upgrade of the VRTSvlic package.

License logging service management

You can manage the infoScaleLicense service using the following commands:
  • Check status:# systemctl status infoscaleLicense
  • Start manually:# systemctl start infoscaleLicense
  • Stop manually:# systemctl stop infoscaleLicense

Log locations

  • Compliance and state messages: License-related alerts for Warning, Grace, and Expired states are written to the system syslog: /var/log/messages.
  • Functional logs: Detailed operational logs for the service itself are located in the /var/opt/VRTSvlic/logs/ directory.

Downloading the license

You can download the subscription-based license from the InfoScale licensing portal by going to the InfoScale licensing portal or by going to InfoScale Download Center and navigating to My account > Licenses.
The subscription license key is a .lic file. You must register with the InfoScale portal to download the key. For additional assistance or questions, you can contact your ATS or Account team representative.

License management utilities

After installing an InfoScale product, you may need to manage licenses for new deployments, upgrades, and renewals. The license key utilities, vxlicinstupgrade and vxlicrep are located in the /opt/VRTS/bin/ directory and handle license operations.

About the vxlicinstupgrade utility

Use this utility to add or remove InfoScale licenses with built-in validation checks.
Supported tasks:
  • Install a new license
  • Remove an old license
If you choose to install the licenses manually using the licensing utilities directly, the license operations (installing/updating) need to be repeated on all the cluster nodes. After which, all InfoScale services will then need to be restarted manually. It is recommended, therefore, to use the automated installer to semlessly deploy licenses on all cluster nodes.
Built-in validation checks: The utility automatically performs the following guardrails during execution: License validity: Rejects invalid license types, including legacy keyless, permanent, and older subscription licenses. Version upgrades: Automatically replaces lower-version licenses with higher ones. For example, if an older Storage license is present and you install a newer version license file, the utility deploys the new license to /etc/vx/licenses/lic and safely deletes the legacy key.
Limitations: Does not support pre-7.4 text-based license keys.
Usage: To add or update a license, run the following commands:
# cd /opt/VRTS/bin
# ./vxlicinstupgrade -k <key file path>
where the <key file path> is the absolute path of the .lic license key file saved on the current node.
Example:
./vxlicinstupgrade -k /downloads/InfoScale_keys/XYZ.lic

About the vxlicrep utility

The vxlicrep utility generates a report of the product licenses in use on your system.
Usage The following options are supported:
Option
Purpose
/opt/VRTS/bin/vxlicrep
Display a summary of all the product licenses on your system.
